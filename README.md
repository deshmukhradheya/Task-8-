# Sales Dashboard - Data Analyst Task 8

Project Overview
This Power BI dashboard visualizes retail sales performance based on a fictional dataset. The goal was to analyze sales trends over time, by region, and by product category.

Tools Used
- Power BI
- Python (for initial data cleaning and adding Region column)

Dataset
- File: retail_sales_dataset_with_region.csv`
- Columns include: Date, Product Category, Total Amount, Region, etc.

Dashboard Visuals
- Line Chart: Monthly sales trend
- Bar Chart: Total Sales by Region
- Donut Chart: Total Sales by Product Category
- Slicer: Filter by 5Region

Key Insights
1. The West region had the highest total sales, peaking in Nov-Dec.
2. Electronics was the top-selling product category.
3. Sales steadily increased from Q2 to Q4.
4. Beauty and Clothing had the lowest average sales.
